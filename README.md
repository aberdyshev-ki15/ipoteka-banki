# Ипотечные банки — PWA

Исходное приложение сохранено без изменения банковской базы и формул. Добавлены манифест, иконки и Service Worker.

## Публикация
Создайте отдельный публичный репозиторий GitHub, загрузите файлы **из этой папки в корень** ветки main. В Settings → Pages выберите Deploy from a branch → main → /(root). Через несколько минут откройте `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

На iPhone откройте адрес в Safari → Поделиться → На экран «Домой». После первой онлайн-загрузки приложение работает офлайн (внешние Google Fonts офлайн заменятся системными).

Данные хранятся в localStorage конкретного браузера и не синхронизируются между устройствами. Очистка данных Safari может удалить настройки. Публичный репозиторий раскрывает исходный HTML, включая контакты и базу условий банков. Перед публикацией проверьте разрешение на размещение контактных данных.

Банковские условия из исходника являются черновиком и требуют проверки актуальности.
